SETUP                                                           *rock-setup*

rock.nvim uses Neovim's native LSP configuration API and requires Neovim
0.11 or newer. Add the checkout's neovim directory in init.lua:

>lua
    vim.opt.runtimepath:prepend("/absolute/path/to/Rock/neovim")
    require("rock").setup()
<

Project dependencies and the toolchain stdlib are discovered automatically from
the nearest rock.toml. An explicit artifact can override a discovered crate for
compiler-development workflows:

>lua
    require("rock").setup({
      extern_artifacts = {
        stdlib = "/absolute/path/to/stdlib.rkca",
      },
    })
<

The plugin registers *.rk as the "rock" filetype. The LSP workspace root is
the nearest directory containing rock.toml, then the nearest .git directory.
Standalone files are also supported.

==============================================================================
OPTIONS                                                       *rock-options*

cmd ~
    String or list used to start the server. By default the plugin checks
    target/release/rock-lsp and target/debug/rock-lsp in the repository root,
    and then $PATH.

extern_artifacts ~
    Table mapping crate names to .rkca artifact paths. Each entry becomes an
    --extern-artifact name=path server argument.

no_prelude ~
    Pass --no-prelude to rock-lsp. Default: false.

autostart ~
    Enable the "rock" LSP config automatically. Default: true.

server ~
    Extra |vim.lsp.Config| fields. These override the defaults from
    lsp/rock.lua. A server.cmd value is used when top-level cmd is absent.

==============================================================================
COMMANDS                                                     *rock-commands*

                                                             *:RockLspInfo*
:RockLspInfo
    Show the resolved Rock LSP configuration and active clients.

                                                          *:RockLspRestart*
:RockLspRestart
    Stop active Rock clients, then re-enable the configuration.

==============================================================================
HEALTH                                                         *rock-health*

Run:

    :checkhealth rock

This checks the Neovim API version, server executable, plugin setup, and active
Rock clients.
